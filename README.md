# 🧠 Flip Game Memory

Flip Game Memory is a simple and engaging card-matching game that challenges your memory, focus, and pattern recognition skills. Flip two cards at a time, remember their positions, and match all pairs to win. Easy to learn, quick to play, and fun for all ages.

## 🎮 How to Play

- Click or tap a card to flip it.
- Flip a second card to try to find a match.
- If the cards match, they stay face up.
- If they don’t match, they flip back over.
- Match all pairs to complete the game.
- Try to finish in the fewest moves possible.

## 🧩 Game Logic Overview

- Cards are duplicated and shuffled using a randomization function.
- Each click stores a selected card.
- When two cards are selected:
  - The game checks for a match.
  - If matched → cards remain flipped.
  - If not matched → cards flip back after a short delay.
- The game ends when all pairs are matched.
